Stable workflow

  1. Dans Live : Export Session Map
  2. Les vues HTML et Mermaid source sont remises à jour
  3. Utilise ce launcher pour ouvrir la vue adaptée
  • Current on export: HTML Report, Session Grid, Mermaid HTML, .mmd
  • Manual renders: SVG/PNG with npm run export:diagram:all
  • SDK Matrix: separate Live diagnostic, refreshed independently
Primary views are current. Some SVG/PNG files are older manual renders, which is fine unless you need fresh static renders.
SDK Capability Matrix is a separate diagnostic report and may be older than the latest export. Refresh it from Live with ENABLE_CAPABILITY_MATRIX=true.
Open without CORS issues
If a Mermaid HTML page does not render from file://: run npm run serve:exports then open http://localhost:5177/exports/session-map-diagrams.html
